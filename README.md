# Hi, I'm Chris 👋

I build practical automation, data and AI tools, mostly for search and content teams. My background is technical SEO, and I'm based in Hampshire, UK.

I like the point where search, data and engineering meet: finding the technical problem, turning messy datasets into clear priorities, and writing the tool that makes the work faster and more reliable.

## What I build

- Automation and internal tools for SEO analysis, reporting and quality assurance
- AI-assisted workflows with human review built in, not bolted on
- Privacy-conscious personal automation and progressive web apps
- Data pipelines around Google Search Console, crawl data and log files

## Featured project

### [Alfred](https://github.com/chrispayneseo/alfred)

A private-by-design, proactive personal-assistant PWA. Alfred brings together tasks, notes, projects, calendars and email into one focused daily system, using Claude and ChatGPT as interchangeable workers. It reads email but never sends it, and every cloud hand-off from its local agent layer needs explicit approval.

Built with React, TypeScript, Vite, Tailwind CSS, PostgreSQL and Vercel, plus a Python service for local, on-device processing.

## Principles

- Solve the real problem, not just the visible symptom
- Automate repetition, not judgement
- Keep recommendations clear enough to implement
- Treat security and privacy as product requirements
- Build useful things, then improve them through real use
